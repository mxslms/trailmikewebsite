# Iceland 2025 photos

Web-ready WebP exports for the Laugavegur journal post.

## Naming

`iceland-2025-MM-DD-NN.webp` (chronological)

## Export targets

- Long edge ~**1280–1800px**
- WebP quality ~80–85 (or JPEG 82–85)
- **Strip GPS**; bake orientation into pixels (don’t rely on EXIF alone)
- Keep originals elsewhere
