# Iceland 2025 photos

Drop web-ready images here, then wire them into `src/content/posts/iceland-2025.md`.

## Naming (suggested)

```
day01-01-landmannalaugar-camp.jpg
day01-02-ridge.jpg
day02-01-hvanngil-trail.jpg
day03-01-thorsmork.jpg
hero.jpg
```

## Export targets (digiKam / any tool)

- Long edge **1800px** (hero up to **2400px**)
- JPEG quality **82–85** or WebP ~80
- **Strip GPS**
- Keep originals elsewhere — only web copies in this folder

## In the post

```md
![Hikers above the steaming valley](/images/iceland-2025/day01-02-ridge.jpg)
```

Set the post hero in frontmatter:

```yaml
coverImage: /images/iceland-2025/hero.jpg
```
